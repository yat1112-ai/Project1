# 🌐 프로젝트: 에코즈 오브 세라피나 - Core Loop UX Flow Map (v1.0)
## 콘셉트 기반: 데이터 아카이브 인터페이스 / 네오-사이버 느와르
### 목표: 로그인부터 상점 접근까지, 모든 과정이 '시스템 접속'처럼 느껴지게 설계한다.

## ⚙️ Part 1. UX Flow Map & 시퀀스 정의 (The Journey)

사용자 경험을 **3단계의 데이터 스트림**으로 분할하여 정의합니다. 각 단계는 이전 단계가 끝날 때마다 반드시 '시스템 전환 효과'를 거쳐야 합니다.

| Step | 화면/상태 (Screen Name) | 핵심 목적 (Goal) | 주요 상호작용 (Interaction) | 시각적 특징 (Visual Focus) |
| :---: | :---: | :---: | :---: | :---: |
| **1** | **[BOOT] 시스템 접속 화면** | 세계관 몰입 및 인증 시작 | 자동 로딩(Loading) 후, 사용자 ID/비밀번호 입력 필드 활성화. | 텍스트 기반의 터미널 출력 느낌 (Monospaced Font), 네온 시안 글리치 효과. |
| **2** | **[MAIN] 아카이브 메인 허브** | 플레이어 위치 및 핵심 정보 확인 | 캐릭터 선택/스토리 진입 버튼 활성화. 시간 경과에 따른 '데이터 패딩' 표시. | 주변 UI는 어둡고 고풍스럽지만, 주요 액션 영역만 네온으로 강조됨. |
| **3** | **[SUB] 스토리 아카이브 (핵심 루프)** | 서사 진입 및 캐릭터 선택 경험 제공 | 특정 캐릭터/이벤트를 '선택'하면, 해당 데이터 파일이 열리는 효과(Glitch-Open). | UI가 문서나 낡은 디스크 조각을 펼치는 듯한 물리적 애니메이션 강조. |
| **4** | **[SUB] 상점 인터페이스 (Resource Hub)** | 구매 유도 및 자원 확인 | 상품 카테고리 선택 $\rightarrow$ '데이터 전송' 버튼 클릭 $\rightarrow$ 상세 정보 열기. | 단순 쇼핑몰 UI가 아닌, '자원 배분 패널'처럼 기능적이고 기계적인 레이아웃 강조. |

## 📐 Part 2. 와이어프레임 & 컴포넌트 명세 (The Blueprint)

각 화면의 구조와 필수 요소들을 정의합니다. (※ 실제 프로토타입에서는 이 구조 위에 애니메이션을 입힙니다.)

### A. [BOOT] 시스템 접속 화면 (Login Screen)
*   **배경:** 미니멀한 블랙 배경에 느리게 움직이는 데이터 스트림(Particle Effect)이 흐름.
*   **핵심 컴포넌트:**
    1.  **[SYSTEM LOG]:** 상단 중앙에 텍스트가 타이핑되는 듯한 애니메이션 (e.g., `CONNECTING TO ECHOS... OK`).
    2.  **[USER INPUT BOX]:** ID/PW 입력 필드. 포커스 시 네온 시안 테두리 깜빡임 효과 필수.
    3.  **[ACCESS BUTTON]:** "시스템 접속" 버튼. 마우스 오버 시, 데이터 왜곡(Glitch) 애니메이션이 잠시 발생하며 활성화됨.

### B. [MAIN] 아카이브 메인 허브 (Home Screen)
*   **레이아웃:** 3분할 구조 (좌: 캐릭터 상태 패널 / 중앙: 주요 스토리라인/퀘스트 로그 / 우: 시스템 알림 및 자원 현황).
*   **핵심 컴포넌트:**
    1.  **[PROFILE DATA]:** 플레이어 이름, 레벨 등은 고전적인 폰트로 처리하되, '데이터 버전'과 같은 사이버펑크 요소를 추가.
    2.  **[STORY ENTRY PANEL]:** 메인 스토리를 나타내는 가장 큰 카드형 컴포넌트. (클릭 유도 지점)
    3.  **[NAVIGATIONAL BUTTONS]:** '스토리 아카이브', '자원 매매소(Shop)', '설정' 등은 버튼이 아닌, **데이터 포트를 연결하는 듯한 아이콘 형태**로 디자인하여 시스템의 일부처럼 보이게 합니다.

### C. [SUB] 스토리 아카이브 (Story/Character Select)
*   **레이아웃:** 컨텐츠 중심형. 왼쪽에는 캐릭터 데이터 카드(Data Card), 오른쪽은 서사 흐름도(Flowchart) 배치.
*   **핵심 컴포넌트:**
    1.  **[CHARACTER DATA CARD]:** 단순히 이미지를 보여주는 것이 아니라, '파일 ID: XXXX'와 같은 식별자와 함께 **데이터 왜곡 필터가 적용된 썸네일**을 사용합니다.
    2.  **[RELATIONSHIP MAP]:** 캐릭터 간의 관계를 일반적인 선이 아닌, **연결되는 네온 전선(Wire)**으로 시각화하여 '시스템적 연결' 느낌을 극대화합니다.
    3.  **전환 효과 (Crucial):** 이 화면에서 특정 캐릭터를 선택하면, 배경이 일시적으로 **데이터 글리치 노이즈(Glitch Noise)**로 뒤덮이고, 해당 캐릭터의 데이터 파일명과 함께 새로운 씬으로 진입하는 애니메이션을 적용해야 합니다.

### D. [SUB] 상점 인터페이스 (Resource Hub)
*   **레이아웃:** 패널형 구조. 중앙에 상품 목록이 아닌, '획득 가능한 자원 유형'별로 분류된 **탭(Tab)** 시스템을 채택합니다.
*   **핵심 컴포넌트:**
    1.  **[RESOURCE CATEGORY TABS]:** (예: 📜 스토리 해제 코드, ✨ 미적 증강 패키지, ⚡ 에너지 부스트). 각 카테고리는 데이터베이스 분류 태그처럼 디자인합니다.
    2.  **[ITEM CARD]:** 상품 설명에 '이 아이템은 현재 아카이브의 **진실 공백(Void)**을 채워줍니다.'와 같은 세계관적 문구를 삽입하여 판매 목적이 아닌, *세계 복구*라는 느낌을 줘야 합니다.
    3.  **구매 액션:** '구매' 버튼 대신 **[DATA TRANSFER] (데이터 전송)** 또는 **[ACQUIRE CODE] (코드 획득)**와 같은 용어를 사용합니다.

## ✨ Part 3. 시각적 시스템 가이드라인 (The Polish)

이 섹션은 모든 애니메이션과 UI 요소의 일관성을 유지하는 규칙입니다.

### 1. 컬러 및 라이팅
*   **메인 색상:** #00FFFF (네온 시안, 데이터 플로우)
*   **강조색:** #FF00FF (마젠타/딥 퍼플, 희소성, 위험 경고)
*   **배경톤:** 짙은 블랙 (#0A0A15) 또는 다크 그레이. 빛이 새어 나오는 듯한(Ambient Glow) 느낌을 유지합니다.

### 2. 애니메이션 및 전환 효과 (The Immersion Engine)
| 상황 | 액션/효과 | 목적 | 구현 방법 가이드라인 |
| :---: | :---: | :---: | :---: |
| **화면 전환** | **Data Glitch Transition** | 시스템 접속 느낌 부여 | 화면이 완전히 어두워지기 전, 네온 시안/마젠타 색상의 노이즈(Noise)가 빠르게 스캔되며 다음 화면으로 넘어가는 효과. (VHS 테이프 오류 느낌) |
| **버튼 클릭** | **Haptic Feedback + Neon Pulse** | 상호작용 피드백 제공 | 버튼을 누르는 순간, 미세한 전기적 떨림(Pulse)과 함께 네온 빛이 번쩍이는 효과를 줍니다. |
| **정보 로딩** | **Typewriter Effect / Data Stream** | 대기 시간의 지루함 해소 | 스토리가 시작되거나 데이터가 불러와질 때, 문장이 '타이핑되는' 애니메이션을 사용합니다. (터미널 느낌) |

### 3. 타이포그래피
*   **헤드라인/시스템 메시지:** `Monospace Font` 계열 (예: Roboto Mono, Courier New). 이는 데이터 아카이브와 코드를 연상시킵니다.
*   **본문 텍스트:** 가독성이 높은 Sans-serif를 사용하되, 색상을 네온 시안으로 처리하여 시스템 메시지처럼 보이게 합니다.
