# 📋 작업 브리프

**원 명령:** 우리가 만들 게임을 라이브 시연도 같이 하면서 볼수있나?

## 요약
지금까지 기획된 '네오-사이버 느와르' RPG 게임의 콘셉트를 실제 플레이 가능한 형태로 시각화하고 기술적 구현 가능성을 검토합니다. 단순한 이미지를 넘어, 사용자가 시스템을 체험할 수 있는 인터랙티브 프로토타입의 초안을 제작하는 것이 목표입니다.

## 분배
- **🎨 Designer**: 기존 '데이터 아카이브 인터페이스' 디자인 브리프와 컬러 팔레트를 기반으로, 게임 핵심 루프(로그인 → 캐릭터 선택/스토리 진입 → 상점 UI)의 흐름을 보여주는 와이어프레임 또는 모형 프로토타이핑 가이드라인을 작성해주세요. 특히 전환 효과와 시스템 규칙이 자연스럽게 녹아드는 'UX Flow Map'에 중점을 두고, 실제 사용자가 볼 수 있는 스크린샷 시퀀스를 정의해주세요.
- **💻 코다리**: 위에서 정의된 UX Flow Map을 바탕으로, 최소 기능 제품(MVP: Minimum Viable Prototype) 구현에 필요한 기술적 아키텍처와 초기 개발 로직(Mockup Code Logic)을 설계해주세요. 특히 '클릭 시 다음 화면 이동' 같은 핵심 상호작용 플로우를 테스트할 수 있는 간소화된 자동화 스크립트(Pseudo-code 또는 React/Vue 등 프론트엔드 기반 모킹 코드의 구조) 초안과 함께, 이 프로토타입이 어떤 환경에서 구동되어야 할지 기술적 제약사항을 명시해주세요.
