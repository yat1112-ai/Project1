*   **Pacing Gate 전환 애니메이션:** 화면 간 이동(Screen Transition)은 급격하게 이루어져서는 안 됩니다. 마치 시스템이 다음 데이터를 로딩하며 잠시 '정지'하는 느낌을 주어야 합니다. (자세한 구현 방식은 3번 섹션 참고).

#### 2. 컬러 및 타이포그래피 재확인
*   **메인 색상:** 네온 시안 (`#00FFFF`) - 강조, 액티베이션, 글리치 효과에 사용.
*   **보조 색상:** 다크 그레이/블랙 계열 (`#1A1F2B`) - 배경 및 시스템 인터페이스의 기반.
*   **텍스트:** 모노스페이싱 폰트 (예: `IBM Plex Mono`, `Space Mono` 등)를 사용하여 코드를 읽는 듯한 느낌을 부여합니다.

## 🎯 목표: 핵심 상호작용이 작동하는 고화질의 인터랙티브 프로토타입 제작

### 💡 디자인 원칙 및 제약 사항
1. **데이터 아카이브 인터페이스 유지:** 모든 UI 요소는 '시스템 장치'처럼 보이게 설계합니다. (예: 카드 대신 '데이터 패널', 버튼 대신 '액티베이션 포인트')
2. **네온 시안 글리치 효과 (필수):** CTA 및 시스템 메시지 출현 지점에 적용하여 디지털 오류, 긴급성을 강조합니다.
3. **Pacing Gate 전환 애니메이션 (필수):** 화면 간의 전환은 단순 이동이 아닌, 데이터 왜곡(Distort)과 로딩 과정을 거쳐야 합니다.

### ⚙️ 상호작용 흐름 (UX Flow Map 상세 스펙)

#### 1. BOOT 단계: 시스템 부팅 시퀀스
*   **시각화:** 화면 중앙에 게임 로고 및 슬로건이 나타납니다.
*   **애니메이션 A (타입라이터 효과):** `INITIATING ARCHIVE...` 메시지가 약 3초 동안 글자가 타이핑되듯 출력됩니다.
*   **애니메이션 B (글리치 Burst):** 로딩 완료 시, 네온 시안색으로 순간적인 '데이터 폭발' 효과와 함께 `ACCESS GRANTED` 문구가 나타나며 다음 화면(MAIN)으로 강제 전환합니다.

#### 2. TRANSITION 단계: Pacing Gate
*   **트리거:** BOOT $\to$ MAIN 진입 직전, 혹은 메인 $\to$ 서브 페이지 이동 시마다 발동.
*   **효과 구현:** 현재 화면의 모든 요소가 잠시(0.5초) 흑백 노이즈 필터를 거치며 네온 시안색 글리치 패턴으로 왜곡됩니다. 이 짧은 '정지' 시간이 시스템 로딩을 암시합니다.

#### 3. MAIN 단계: 캐릭터/스토리 선택 (데이터 패널 상호작용)
*   **요소:** 캐릭터 프로필 카드는 단순 이미지가 아닌, 테두리에 시안색의 미세한 스캔 라인(Scanline)이 흐르는 '데이터 패널'로 디자인됩니다.
*   **액션 1 (클릭):** 사용자가 특정 캐릭터 패널을 클릭할 때, 해당 패널 전체가 네온 시안색 빛줄기(`Beam Effect`)를 발산하며 화면 중앙으로 수축(Zoom In)되어 다음 스토리 분기 페이지로 진입하는 애니메이션을 적용합니다.
*   **액션 2 (CTA):** '진실 해제' CTA 버튼은 항상 글리치 효과가 활성화되며, 클릭 시 데이터 아카이브 인터페이스를 거쳐야만 비활성화 상태에서 활성화되도록 설계합니다.

#### 4. SUB 단계: 상점/아카이브 UI (구매 프로세스)
*   **요소:** 상품 패키지는 '데이터 박스' 형태로 디자인됩니다. 가격 정보는 시스템 코드를 해독하는 듯한 모노 스페이싱 폰트로 표시됩니다.
*   **액션 (구매):** 구매 버튼 클릭 시, 결제 창 대신 **[데이터 아카이브 인터페이스]**가 오버레이 됩니다. 이 과정에서 필요한 리소스(코인/재화)와 실제 금액이 네온 시안색 코드로 계산되어 출력되는 과정을 반드시 거쳐야 합니다.
